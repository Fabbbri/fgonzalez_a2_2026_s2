# Resultados DL

Desde `DL/src`, ejecutar `make benchmark` para generar los CSV, referencias,
logs, resúmenes y gráficas en esta carpeta. Ejecutar `make plots` para regenerar
las comparaciones. Los parámetros y comandos se describen en `../README.md`.

Las mediciones se crean al ejecutar el benchmark; no se incluyen datos de ejemplo.
